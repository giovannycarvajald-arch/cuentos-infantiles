# La Casita de los Cuentos 📚

Biblioteca digital infantil en español, adaptable a celulares, tabletas y computadores.

## Funciones
- Cuentos originales organizados por categorías.
- Búsqueda de cuentos.
- Favoritos guardados en el dispositivo.
- Lectura por escenas con indicador de progreso.
- Lectura en voz alta mediante la voz disponible en el navegador.
- Ajuste del tamaño de letra.
- Diseño adaptable y funcionamiento como aplicación web instalable (PWA).

## Publicar con GitHub Pages
1. Abre **Settings** del repositorio.
2. Entra en **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama **main** y la carpeta **/ (root)**.
5. Pulsa **Save**.

La aplicación estará disponible en:
https://giovannycarvajald-arch.github.io/cuentos-infantiles/

Los favoritos y el progreso se guardan en el almacenamiento local del navegador de cada dispositivo.
